# Fonts

Servides des d'aquí perquè la web no depengui de cap servei extern i funcioni
sense connexió.

- **Bricolage Grotesque** — Mathieu Triay. SIL Open Font License 1.1.
- **IBM Plex Sans** i **IBM Plex Mono** — IBM. SIL Open Font License 1.1.

El text de la llicència és a `OFL.txt`. Els fitxers són els subconjunts
`latin` i `latin-ext` que serveix Google Fonts; les declaracions
`@font-face` són a `../css/fonts.css`.
